# 分镜写法和零件

坐标都是设计空间 1920×1080：x 往右、y 往下。`(cx, cy)` 是中心点，`(x, y, w, h)` 是左上角加宽高，`s` 是缩放。

```tsx
import { Beat, b, d, h, fly, mv, fade } from '../engine/beat';
import { C, box, chip, dash, ln, ring, dot, scribble, star, tri, zig, cab, pl } from '../engine/kit';
import { t, ar, dr, bg, ROOMBLUE, DARK, GREY } from '../engine/kit'; // 简写和三个额外颜色，用到再导入
import * as L from '../engine/lib';
import { PAL } from '../engine/lib';
```

## 一拍：`b(句, 分句, ...步骤)`

句从 1 数，分句从 0 数，和 `data/script.json` 里的顺序对应。步骤按顺序一个接一个执行。

| 步骤 | 写法 | 说明 |
|---|---|---|
| 画笔画 | `d(parts, 选项)` | `parts` 是一组笔画（`Part[]`）。**同一个 `d()` 里的笔画紧挨着画，中间不留空**；带 `fill` 的笔画勾完再上色 |
| 手写字 | `h(文字, x, y, 选项)` | 选项：`size` 字号、`color`、`center: true`（或展开 `...C`）水平居中、`rot` 旋转角度、`maxW` 放不下就缩小。**`y` 是文字的底线，不是中心**，见下面 |
| 飞信封 | `fly(pl([x0,y0],[x1,y1]), 秒, 选项)` | 一个信封沿路径飞过去；选项 `label` 写在信封上，`keep: true` 飞到后留着 |
| 整组让位 | `mv(组名, x, y, 缩放, 秒)` | 把一组已经画好的东西平移加缩放；不占笔的时间。算法见下面 |
| 整组擦掉 | `fade(组名, 秒)` | 一组东西淡出；不占笔的时间 |

所有步骤都能加两个选项：

- `at: '口播词'`：等念到这个词再开始。这个词必须出现在本分句里，否则校验报错。锚词只认汉字、字母和数字，标点和 `%` 会被去掉：稿子写"进步 1%"，锚词写 `'1'` 或 `'进步'`，不能写 `'1%'`。**只有这一拍的第一个步骤最多等 0.4 秒；后面的步骤会一直等到这个词念出来**，所以锚词在分句末尾时，锚在它上面的东西几乎没有时间画。
- `group: '组名'`：归到一组，之后能用 `mv`、`fade` 整组操作。

### 手写字的位置

`h()` 的 `y` 是文字底线。不加 `center` 时 `x` 是文字的左边；加了 `center`，`x` 是文字的水平中点。竖直方向永远不居中。要把字放进一个框里、竖直居中：

```tsx
// 框：box(x, y, w, hh)；字号 size
h('文字', x + w / 2, y + hh / 2 + size * 0.36, { ...C, size })
```

`chip(…)` 就是这么算的，框里放字优先用它。

### 整组让位怎么算

`mv('组名', x, y, s)` 做的是"先缩放 s 倍、再平移 (x, y)"，缩放的原点是画面左上角 (0, 0)。组里原来在 (px, py) 的点会移到：

```
(x + s·px, y + s·py)
```

所以 `x, y` 是新的原点位置，不是"移到哪里"。想让一组内容（原来的外框左上角在 (X0, Y0)）缩到 s 倍、左上角落在 (TX, TY)：`x = TX − s·X0`，`y = TY − s·Y0`。同一组可以 `mv` 多次，每次都从上一次的位置过渡到新的值。

## 小零件（`kit.ts`）

这些返回**一笔**，要放进数组：`d([box(…), ln(…)])`。

画多久 = 笔画长度 ÷ 1600 秒，最短 0.04 秒；带填色的再加 0.28 秒上色（不占笔的时间）。表里给了长度的估法。

| 零件 | 写法 | 笔画长度约等于 |
|---|---|---|
| 圆角框（带墨线和填色） | `box(x, y, w, h, 填色=奶油色, 线宽=4.2, 圆角=14)` | 周长 2(w+h)：300×200 的框 1000，0.63 秒 |
| 直线 | `ln(x0, y0, x1, y1, 线宽=3, 颜色)` | 两点距离 |
| 虚线（可弯） | `dash([x0,y0], [x1,y1], [控制点]?, 颜色=珊瑚红)` | 两点距离，弯的多一点 |
| 红笔圈 | `ring(cx, cy, rx, ry, 颜色, 线宽)` | 约 π(rx+ry) |
| 圆点（**带墨线描边**的实心圆，不用再叠一个圈） | `dot(cx, cy, r, 填色)` | 2πr：r=40 时 250，0.16 秒 |
| 乱涂一团 | `scribble(x, y, w, h, 次数, 颜色)` | 约 次数 × 2h |
| 星星 | `star(cx, cy, r, 填色)` | 约 7r：r=30 时 210，0.13 秒 |
| 三角形 | `tri([x,y], [x,y], [x,y], 填色)` | 周长 |
| 折线 | `zig([[x,y], …], 颜色, 线宽)` | 各段长度之和 |
| 路径（给 `fly` 用） | `pl([x0,y0], [x1,y1])` | 不画，只是路径 |

箭头 `L.arrow` 的长度是杆长加两个箭头头（各 26）：杆长 200 的箭头约 250，0.16 秒。

这些返回**一组**，直接用：

| 零件 | 写法 |
|---|---|
| 简易档案柜 | `d(cab(x, y, w, h))` |
| 带字的块 | `...chip(x, y, w, h, 填色, 文字, 字号, 选项)`（返回两个步骤：先画框、再写字，前面要加 `...`） |

还有几个简写（都从 `kit` 导入），写起来短一点：`t(文字, x, y, 字号, 颜色)` 是居中的 `h`；`ar(起点, 终点, 控制点?, 颜色)` 是 `d(L.arrow(…))`；`dr(parts)` 就是 `d(parts)`；`bg('组名', 句, 分句, …步骤)` 是把这一拍所有步骤都归到同一组的 `b`。另有三个颜色（也从 `kit` 导入）：`ROOMBLUE` 浅蓝、`DARK` 深蓝紫、`GREY` 灰。

## 图库（`lib.tsx`，`L.xxx`）

除了 `dashedLine` 返回一笔（要写 `d([L.dashedLine(…)])`），其他都返回一组，直接 `d(L.xxx(…))`。

图库里没有的东西，用 `box`、`ln`、`dot`、`tri`、`L.arrow` 自己拼，或者照 `lib.tsx` 的写法新加一个。

## 颜色

`PAL`：`cream` 奶油、`yellow` 黄、`coral` 珊瑚红、`teal` 青、`kraft` 牛皮纸、`pink` 粉、`lilac` 淡紫、`green` 绿、`sky` 天蓝、`night` 深蓝、`ink` 墨色（默认线色）、`skin` 肤色。

底纸 `ground`：`sky`、`mint`、`sand`、`lilac`、`cream`、`night`。

线的颜色要和底纸拉开：`GREY`、`cream`、`yellow`、`pink` 当线色时，在浅色底纸（`sky`、`mint`、`sand`、`lilac`、`cream`）上几乎看不见，只适合当填色。要画"次要的、对照用的"线，用 `ink` 加虚线，或者 `teal`。`night` 底纸上反过来，线用 `cream`。

## 讲解稿的可选参数（`data/script.json`）

`title` 只是给人看的备注，可以省掉，程序不读它。`cps` 语速（每秒几个汉字，默认 4.2），`gapClause` 分句间停顿（默认 0.25 秒），`gapSentence` 句间停顿（0.5），`lead` 场景开头空白（0.3），`tail` 场景结尾留着看完整画面的时间（0.9）。

这几个参数用来贴近真实说话的节奏，**不要拿来修校验失败**：画不完就减内容，不要靠加停顿等画面。

数字会按中文念法估算（25 念三个字、15 念两个字、四位数按一位一个字），`%` 加三个字（百分之）。

## 时间表格式（以后接配音用）

`data/timing.json` 由 `npm run timing` 按讲解稿估算生成。要按真实录音对齐，就生成同样格式的文件替换它：

```json
{ "scenes": [ { "id": "S1", "ground": "sky", "start": 0, "next": 10.7,
  "sentences": [ { "n": 1, "spoken": "整句原文", "start": 0.3, "end": 2.2,
    "norm": "去掉标点和空格后的小写文字", "times": [0.3, 0.54, …],
    "clauses": [ { "text": "分句原文，", "start": 0.3, "end": 2.2 } ] } ] } ] }
```

- 时间都是秒，从整片开头算起；`next` 是下一个场景的起点。
- `times` 的长度必须等于 `norm` 的字数，第 k 个值是第 k 个字被念到的时间。`at` 锚词就是靠它找时间的。
- `npm run check` 会先跑 `timing` 重新估算。接配音以后，要把 `package.json` 里 `check` 开头的 `node scripts/timing.mjs &&` 去掉，否则估算的时间表会把录音的覆盖掉。
